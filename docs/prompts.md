# 提示词编辑器

**文件 → 提示词…**（`Ctrl+P`）打开独立窗口，直接改随包内置的提示词。改动写进数据目录的 `prompts/` 下，**只覆盖动过的键**：读取时按「覆盖层 → 内置」逐键回退，所以删掉某个键不会让整份文件失效。保存后下一条任务的写稿 / 检索就生效，已生成的任务不受影响。

可改的 11 个字段：

| 文件 | 字段 | 作用 |
| --- | --- | --- |
| `podcast.json` | 写稿 / 润色 | 播客的结构、段数与语气 |
| `crosstalk.json` | 写稿 / 润色 | 相声的结构与包袱密度 |
| `talkshow.json` | 写稿 / 润色 | 脱口秀的结构与吐槽方式 |
| `critic.json` | 审稿 / 按意见返修 | 打分维度与返修方向，写得太严会把稿子改回工整 |
| `material.json` | 检索词 | 台词转外网英文关键词 |
| `video_select.json` | 选片 | 按标签挑素材 |
| `vision_select.json` | 视觉选片 | 看缩略图挑素材，也更容易挑到不相关画面 |

几点：

- `{{SPEAKER_MAIN}}` / `{{SPEAKER_GUEST}}` 是角色名占位符，写稿前按设置里的角色名替换，改文案时别删。
- 「恢复默认值」只删掉这一键的覆盖，文件空了连文件一起删，重新回到内置默认；提示词不能存空值。
- 也可以直接编辑 `<数据目录>/prompts/*.json`（格式与内置文件相同），存盘即生效 —— 读取按 `mtime` + 文件大小判断，不用重启后端。目录入口：**文件 → 打开数据目录**。
- 只开放上表这些文件与键，接口不接受任意文件名，避免写到别处。
- 开发态也可以直接访问前端地址下的 `/prompts.html`。

覆盖层目录可用 `AISV_USER_PROMPTS_DIR` 改到别处，见 [configuration.md](configuration.md#环境变量)。
